# Setup and Configs Context

Environment configuration and bootstrap scripts.

## Contents
- `setup*.sh`: Scripts to configure remote or local environments.
- `lora_config.yaml`: Configuration for LoRA fine-tuning parameters.
- `hosts.json`: Remote host configurations.
- `tnr_key_*`: SSH/API keys for various services.
- `training-babysitter.skill`: Instructions for the automated training monitor.
