# ML Data Context

This directory manages all data stages for the project.

## Sub-directories
- **[raw/](raw/AGENTS.md)**: Original, un-transformed datasets.
- **[processed/](processed/AGENTS.md)**: Formatted datasets ready for MLX or Unsloth training.
- **[archives/](archives/AGENTS.md)**: Zip archives of datasets and bundles for backup or remote transfer.
- **[metadata/](metadata/AGENTS.md)**: Tracking files and analysis samples.
