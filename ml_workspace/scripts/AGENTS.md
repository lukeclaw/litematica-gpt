# ML Scripts Context

This directory contains all Python scripts used in the ML pipeline.

## Sub-directories
- **[data_prep/](data_prep/AGENTS.md)**: Dataset generation, parsing, formatting, and preparation.
- **[train/](train/AGENTS.md)**: Training scripts for various models (MLX, Unsloth).
- **[evaluate/](evaluate/AGENTS.md)**: Model evaluation, inference testing, and consistency checks.
- **[utils/](utils/AGENTS.md)**: General orchestration, config fixing, and monitoring helpers.
