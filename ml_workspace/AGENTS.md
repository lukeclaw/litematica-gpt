# ML Workspace Context

This directory consolidates all assets related to the Machine Learning pipeline for Litematica-GPT, specifically focused on fine-tuning Gemma 4 models for Litematica DSL generation.

## Sub-directories
- **[scripts/](scripts/AGENTS.md)**: Python scripts for data preparation, training, evaluation, and utilities.
- **[data/](data/AGENTS.md)**: Raw, processed, and archived datasets.
- **[models_and_adapters/](models_and_adapters/AGENTS.md)**: Trained LoRA adapters and model artifacts.
- **[setup_and_configs/](setup_and_configs/AGENTS.md)**: Environment setup scripts, keys, and model configurations.
- **[logs_and_runs/](logs_and_runs/AGENTS.md)**: Logs, active training runs, and investigation artifacts.
